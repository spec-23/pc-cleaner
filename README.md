Features
Junk File Cleanup: Remove temporary files from common system and user directories.

Cache Clearing: Clear caches from popular applications and browsers.

Safe by Design: Focuses on non-essential files to reduce the risk of deleting important system data.

Lightweight & Fast: Runs quickly with minimal resource usage.

Windows-Oriented: Built with Windows environments in mind (batch/PowerShell/script-friendly workflows).

Usage Notes
Run as needed: Use when your disk space is low or as part of routine maintenance.
Review before cleaning: If using a script/batch version, review what paths are targeted to ensure they match your setup.
Close applications: For best results, close browsers and apps that may be actively writing to caches/temp directories before running.
Back up if unsure: If modifying or extending the cleaner, test in a safe environment or back up important data first.
